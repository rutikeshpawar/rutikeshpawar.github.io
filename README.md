# Rutikesh Pawar — Data Analyst Portfolio

Professional portfolio built with **Vite 7**, **React 19**, **TypeScript 5.9**, and **Tailwind CSS v4**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
```

Output is in `dist/`. Deploy `dist/` to Vercel, Netlify, or GitHub Pages.

## Deploy to GitHub Pages

In `vite.config.ts` add `base: '/your-repo-name/'` (e.g. `base: '/portfolio/'`), then:

```bash
npm run build
```

Upload the contents of `dist/` to your `gh-pages` branch or use a GitHub Actions workflow.

## Resume

Place `Rutikesh_DA_Resume.pdf` in the `public/` folder so the "Download Resume" button works. The link points to `/Rutikesh_DA_Resume.pdf`.
